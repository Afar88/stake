Testnet only — Base Sepolia + Reactive Lasna. No real money. Built for the Reactive Omni Buildathon.

STAKE

Lock ETH on a weekly goal. A friend confirms each week. Miss a week, lose that week's slice. Finish the goal, get the rest back. No bot, no server — a Reactive Network contract does the chasing.

How it works

1
Your goal on Base SepoliaStake locks in the vault, split into weekly slices.
2
Reactive watcher on LasnaIt mirrors every goal and check-in, chain to chain.
3
Cron tickThe network itself wakes the watcher when a week ends.
4
Callback settles the weekConfirmed slice carries on; missed slice goes to penalty. Automatic — no one has to press anything.
